## Featured project

### [RunEXE](https://github.com/CDJuaum/RunEXE)

Analyze Windows applications and run them on Linux through Wine or Proton.

RunEXE brings executable inspection, runtime discovery, dependency checks, and isolated application environments into a Qt desktop app and command-line interface.

[Explore the code](https://github.com/CDJuaum/RunEXE) · [Visit the website](https://runexe.rrmtools.uk/) · [Get the latest release](https://github.com/CDJuaum/RunEXE/releases/latest)
